# ATmega128A 마이크로마우스

2025.09–12 · 마이크로프로세서 응용 설계 및 실험 · 개인 프로젝트

ATmega128A의 레지스터를 직접 설정해 IR 센서 3개와 스텝모터를 제어하고, 방문 기록과 좌표 스택을 이용한 미로 탐색 로직을 작성했습니다. 만능기판에 센서·모터 회로를 배선했습니다.

## 하드웨어와 개발 환경

| 항목 | 구성 |
| --- | --- |
| MCU | ATmega128A, 외부 클럭 16 MHz |
| 센서 | 전방·좌측·우측 IR 센서(EL-7L), ADC0–2 |
| 구동 | 스텝모터 2개, SLA7026 드라이버, 1-2상 여자 |
| 개발 | C, Microchip Studio |

## 직접 구현한 기능

- **센서 입력:** ADC 채널을 선택한 뒤 첫 변환값을 버리고 4회 측정 평균을 사용했습니다. IR 발광부는 PB5–PB7로 제어합니다. ([Sensor.c](Sensor.c))
- **벽 판정:** 전방 센서에 서로 다른 ON/OFF 임계값을 적용해 경계값 부근의 판정 흔들림을 줄였습니다. ([Algorithm.c](Algorithm.c))
- **직진 보정:** 좌우 센서값 차이 `err = left - right`에 P 제어를 적용하고 출력을 ±300으로 제한했습니다. 현재 설정은 Kp=1, Ki=0, Kd=0입니다. ([Algorithm.c](Algorithm.c))
- **탐색:** `visited` 배열과 좌표 스택을 사용해 DFS 방식의 탐색·되돌아가기 로직을 작성했습니다. 다음 방향은 좌·전·우 순서로 확인합니다. ([Algorithm.c](Algorithm.c))
- **모터 구동:** PD4–PD7, PE4–PE7에 1-2상 여자 시퀀스를 출력하고, 회전각을 스텝 수로 변환했습니다. ([StepMotor.c](StepMotor.c))

## 디버깅 기록

- **JTAG과 GPIO 충돌:** PF4–PF6을 상태 표시용 GPIO로 사용하기 위해 JTD 비트를 연속 설정해 JTAG을 비활성화했습니다. ([main.c](main.c))
- **오른쪽 모터 배선 방향:** 오른쪽 모터의 상 순서가 반대여서 전진 명령 시 시퀀스 인덱스가 감소하도록 매핑했습니다. ([StepMotor.c](StepMotor.c))
